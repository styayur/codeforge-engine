# CodeForge Engine v1.1.1

CodeForge Engine v1.1.1 is a stability patch for baseline rule migration and
benchmark provenance discovered while auditing v1.1.0.

## Fixed

- A baseline entry that still matches a current diagnostic but was reviewed under
  an older rule-semantics version is now marked `Stale` and routed to human review.
  It is no longer silently treated as an accepted suppression.
- Benchmark environment metadata now resolves Git revision and worktree state from
  the benchmark project root rather than CodeForge's current working directory.
- Clean benchmark worktrees are recorded explicitly instead of being omitted.

## Compatibility

- Baseline schema remains 1 and existing baseline files remain readable.
- Review JSON and benchmark JSON changes are additive or correctional; no CLI
  command is removed.
- SARIF and Fleet formats are unchanged.
- Rust 1.90 remains the declared MSRV.

## Verification

The patch is covered by a matched-stale baseline regression test and a target-root
benchmark environment test. Release artifacts are rebuilt, smoke-tested and
checksum-verified from the v1.1.1 tag candidate.
