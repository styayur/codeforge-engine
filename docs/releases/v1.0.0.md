# CodeForge Engine v1.0.0

**Release draft — unreleased.** The latest published package remains the v0.2.2
prerelease. No v1.0.0 binaries or new compatibility guarantee are announced.

## Why it exists

CodeForge connects repository analysis, source context, transformation previews,
verification and evidence. It helps reviewers understand a proposed change and
the checks behind it, while retaining each language's native parser and tools.

## Capabilities

Stable workflows include multi-language review, reviewed baselines, transaction
history and rollback, configurable compiler/test checks, SARIF export and Fleet
automation with independent repository tasks. Stable task identity, guarded PR
retries and evidence-linked tracing support repeatable automation.

On-demand context/impact suggestions and local SARIF path import/CodeQL execution
are Experimental and available in current source, absent from v0.2.2. They remain
opt-in, without default downloads or tool startup. Exact excerpts carry source
positions; name-based relations and test suggestions remain heuristic.

## Verification and evidence

Finding a problem is not proof that a fix is correct. Static findings and
external path evidence do not authorize application. Fleet requires successful
policy-required checks; a missing tool is not a pass. Tests cover transaction,
baseline, policy, context bounds and external-output failure behavior. Fake-CLI
testing does not certify a real CodeQL installation or semantic equivalence.
Final v1.0.0 artifacts still require platform release validation.

Startup observations vary with tool discovery and environment; no default scan
speedup is claimed. The measured merged CLI grew approximately 2.81% without new
Rust dependencies. Optional analysis is outside the default scan path.

## Security and limitations

Built-in analysis works locally without an account, telemetry or hosted model.
External commands inherit host permissions/environment and may access the network;
timeouts and temporary workspaces are not an OS sandbox. Reports can contain
source, paths and tool output. Inspect evidence before sharing it.

Impact analysis is bounded and lacks complete type/scope resolution. Configured
equivalence-command success is not a built-in formal proof. CodeQL requires a
separately eligible, user-supplied installation. CodeForge remains independent
and Apache-2.0 licensed. Version alignment, MSRV, installer smokes and final
artifact/checksum validation remain gates before a formal stable tag.
