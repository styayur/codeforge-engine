# Security policy

Read the [security model](docs/SECURITY.md) for process, source and evidence
boundaries. The latest published package is the v0.2.2 prerelease; v1.0.0 is not
released. There is no long-term-support or security-response-time guarantee.

Use [GitHub private vulnerability reporting](https://github.com/styayur/codeforge-engine/security/advisories/new)
when enabled. If it is unavailable, open a public issue requesting a private
contact **without including exploit details, secrets or confidential source**.
Share reproduction steps, affected revision and impact privately once a channel
has been established.
